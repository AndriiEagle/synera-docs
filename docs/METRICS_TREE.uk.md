# C09.L4 Synera Metrics Tree

## 1. North Star Metric (NSM)
**Кількість успішних взаємних метчів (B-Matching Matches), які призвели до розблокування контактів.**
Ця метрика найкраще відображає основну цінність продукту: поєднання двох людей із взаємодоповнюючими потребами.

## 2. Ключові метрики активності (Input Metrics)
- **Active Need Profiles (ANP):** Кількість опублікованих і ще не прострочених (Freshness Decay < 100) профілів потреб.
- **Match Proposals Sent:** Кількість надісланих запитів на метч.
- **Cycle Exchange Engagements:** Відсоток користувачів, які скористалися циклічним обміном (M09).

## 3. Guardrail Metrics (Метрики безпеки)
Ці метрики гарантують, що ми не ламаємо продукт, намагаючись покращити NSM:
- **Spam / Reject Rate:** Відсоток відхилених запитів на метч (повинен бути < 20%, інакше B-Matching працює погано).
- **Time to First Match (TTFM):** Час від публікації профілю до першого взаємного метчу. Якщо він зростає — падає ліквідність.
- **Churn Rate:** Відсоток видалених акаунтів після першого невдалого циклу.

## 4. Фінансові метрики (Business / C11)
- **CPA (Cost per Acquisition):** Вартість залучення одного активного профілю.
- **Revenue per Match / ARPU:** (Для фази монетизації B2B/Pro).
- **AI Cost per Profile:** Витрати на LLM парсинг (GLM-5.2 / Kimi K3) на один створений профіль. Повинен прямувати до $0.00 через Domovyk.
