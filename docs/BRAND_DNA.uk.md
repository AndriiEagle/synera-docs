# C06.L1 Synera Brand DNA

## 1. Обіцянка (Promise)
Synera гарантує приватний, математично точний та цілеспрямований простір для професійних знайомств. Ми усуваємо соціальний шум, покладаючись на алгоритмічну взаємність (B-Matching, Need Decay) замість сліпого свайпінгу.

## 2. Голос (Voice)
Спокійний, впевнений, лаконічний. Без зайвого хайпу, без "магії штучного інтелекту". Ми говоримо фактами, математикою та повагою до часу користувача.

## 3. Три ключові слова
1. **Детермінованість** (Точний результат, прозорі правила, жодних чорних скриньок).
2. **Приватність** (Контроль доступу, RLS, "лише я", відсутність відкритого каталогу).
3. **Ефективність** (Мінімум дій для максимального результату, B-Matching квоти).

## 4. Заборони (Taboos)
- **Жодного нескінченного скролінгу**: У нас немає стрічки профілів.
- **Жодного "AI Magic"**: Не використовуємо ШІ для прийняття рішень за користувача, лише для парсингу та аналітики.
- **Жодних публічних рейтингів людей**: Ми оцінюємо *кейс* і *взаємність*, а не "цінність" самої людини.
- **Ніяких прихованих алгоритмів**: Всі правила старіння потреб та квот є відкритими.
